# تقرير تدقيق عالم العلوم V23

**التاريخ:** 6 نوفمبر 2026  
**النسخة:** 2.2.1+23  
**الأساس:** V22  
**الحالة:** حزمة مصدر مدققة جزئيًا — ليست APK جاهزًا للنشر.

## 1. ما تم تغييره في V23

1. رفع رقم إصدار Android إلى `2.2.1+23` مع الحفاظ على V22 كأساس.
2. إصلاح خدمة المساعد الذكي حتى تعرض رسالة الخادم الفعلية بدل رسالة خطأ مكررة.
3. إصلاح Edge Function للمساعد الذكي: لم يعد يتجاهل سياق الدرس؛ يرسل سياقًا محدودًا إلى النموذج مع تعليمات تمنع التعامل مع نص السياق على أنه تعليمات نظام.
4. إضافة تحقق خادمي من أن المستخدم يملك اشتراكًا ذهبيًا فعالًا قبل تشغيل المساعد الذكي. يتحقق الخادم من جلسة Supabase ثم يقرأ اشتراك المستخدم نفسه، ويتحقق من الحالة والمدة؛ لا يعتمد على قيمة يرسلها التطبيق.
5. تحديد حد أقصى لطول السؤال والسياق وعدد رموز إجابة الذكاء الاصطناعي.
6. إضافة فحص صياغة Edge Function إلى GitHub Actions وCodemagic وإلى فحص المشروع المحلي.
7. تحديث أسماء ملفات البناء التجريبي لتطابق V23.

## 3. فحوصات لم تنجح/لم يمكن تشغيلها

- أمر `python3 scripts/validate_project.py --production` **مرفوض كما هو متوقع** لأن بنك الأسئلة المعتمد فارغ. هذا حاجز حماية مقصود وليس نجاحًا لإصدار الإنتاج.
- لم تتوفر أوامر `flutter` أو `dart` أو `adb` أو Gradle Wrapper في بيئة الفحص.
- تعذر تنزيل Flutter SDK لأن اسم مضيف التنزيل لم يُحلّ في بيئة التنفيذ.
- لم تُشغّل أوامر `flutter pub get` أو `flutter analyze` أو `flutter test` أو `flutter build apk --release`.
- لم يُثبّت APK على هاتف ولم تُنفّذ اختبارات واجهات أو اتصال على Android فعلي.
- لم يتم الاتصال بمشروع Supabase الحقيقي، أو تشغيل SQL migrations، أو اختبار RLS وAuth وSMTP وStorage وEdge Functions على الخادم.
- لم يتم اختبار OpenAI لأن نشر Edge Function وإعداد أسرار الخادم غير متاحين في هذه البيئة.
- لم يتوفر Keystore دائم يملكه صاحب التطبيق؛ لا يوجد APK موقّع إصدار رسمي داخل الحزمة.

## 4. حالة المحتوى التعليمي

- فهرس المنهاج: **9 مواد / 52 وحدة / 237 درسًا**.
- في الدروس الـ237، حالات الملخص والمثال المحلول والأخطاء الشائعة والتدريب لا تزال معلّقة على مراجعة الكتاب/المدرس، ومحتوى هذه الحقول فارغ (`null`).
- بنك الأسئلة الذي يُضمّن في التطبيق: **0 سؤال معتمد**؛ لا تظهر أسئلة مسودة للطالب.
- توجد 18 مسودة للدرس الأول في اللغة العربية: 6 مجانية و12 مدفوعة، وجميعها `draft_needs_teacher_review`. لا يجوز عرضها على الطلاب قبل مراجعة المدرس والمصدر والصفحات والإجابات.
- الأرشيف القديم الذي يحوي 120 سؤالًا محفوظ للمراجعة فقط، وليس بنكًا نشطًا؛ كما أن بيانات مصادر بعض عناصره ناقصة.
- بناءً على ذلك، لا يصح وصف وضع الاختبارات دون إنترنت بأنه مكتمل المحتوى الآن.

## 6. متطلبات تفعيل الخدمات

### المساعد الذكي

انشر المجلد `supabase/functions/ai-chat`، ثم اضبط أسرار الخادم:

- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY` أو `SUPABASE_ANON_KEY`
- `OPENAI_API_KEY`
- `AI_PROVIDER=openai` عند الحاجة

يجب التأكد من وجود عمود `tier` وقيمته `gold` في جدول `subscriptions`، وأن سياسات RLS تسمح للمستخدم بقراءة صف اشتراكه فقط. المساعد الآن يرفض المستخدم غير المشترك بخطة Gold.

### البريد والاستعادة

اضبط SMTP ورسالة OTP وعنوان إعادة التوجيه `scienceworld://login-callback/` في Supabase Auth قبل اختبار الحسابات.

### البناء الرسمي

الإصدار الرسمي يحتاج Keystore دائمًا محفوظًا لدى مالك التطبيق مع الأسرار المذكورة في `docs/release/ANDROID_RELEASE_SIGNING_AR.md`. ملف Debug-signed، إن أُنتج عبر CI، مخصص للمعاينة ولا يصلح كتوقيع نشر دائم.

## 7. الحكم النهائي

**ما يمكن تأكيده:** اجتازت ملفات المشروع والبيانات الأساسية وفحوصات Python وJavaScript وShell وYAML المذكورة أعلاه. وأُضيف تحقق خادمي لاستحقاق المساعد الذكي.

**ما لا يمكن تأكيده:** أن التطبيق يُبنى أو يفتح أو أن جميع الصفحات والاتصالات تعمل على هاتف حقيقي؛ لم تتوفر بيئة Flutter/Android ولم تُختبر خدمات Supabase الحية.

**قرار النشر:** لا تنشر هذه الحزمة كإصدار تعليمي نهائي الآن. يلزم أولًا تشغيل Flutter CI بنجاح، ثم إعداد الخدمات، وإضافة ومراجعة المحتوى التعليمي الرسمي، ثم اختبار APK على جهاز Android وتوقيعه بمفتاح دائم.
