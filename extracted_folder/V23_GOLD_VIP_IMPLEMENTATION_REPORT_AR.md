# تقرير إضافة مزايا الاشتراك الذهبي VIP — عالم العلوم V23

**التاريخ:** 7 نوفمبر 2026  
**النسخة المصدرية:** V23 (2.2.1+23)  
**التعديل:** تحديث كتالوج الخطط، سجل صلاحيات المزايا، واختباراتها، وإضافة ترحيل SQL لمدد الاشتراك المعتمدة.

## 1. ما أُضيف إلى ملفات المشروع

1. تسجيل مدة الفضي **30 يومًا** والذهبي **75 يومًا** في `PlanCatalog`.
2. توسيع وصف الباقة الفضية لتشمل سؤالين إضافيين لكل درس، والملخصات والأمثلة المنشورة، والتنزيل المحدود، واستئناف الاختبارات، ومراجعة الأخطاء والتحليل الأساسي ودفتر القوانين وشارة الفضي.
3. توسيع وصف الذهبي VIP ليشمل جميع المزايا الست مجموعات التي أرسلها صاحب المشروع: فتح المحتوى، مدرس AI، نظام التفوق، الاختبارات الاحترافية، أدوات VIP، ومركز الإنجازات.
4. تسجيل مفاتيح صلاحيات واضحة لكل ميزة فضية وذهبية في `PremiumFeatureAccess`؛ الذهبي يرث مزايا الفضي، والفضي لا يفتح مزايا الذهبي، وأي مفتاح غير معروف يبقى مغلقًا.
5. تحديث صفحة عرض الخطط لتعرض المدتين المعتمدتين، مع إبقاء السعر غير محدد وعدم فتح الدفع قبل اعتماد السعر.
6. إضافة ترحيل قاعدة بيانات `20261107_v23_vip_plan_durations.sql`: يضبط أكواد التفعيل غير المستخدمة على 30 يومًا للفضي و75 يومًا للذهبي، ويحافظ على مدد الأكواد المستخدمة سابقًا كسجل تاريخي.
7. تحديث اختبارات كتالوج الاشتراك وصلاحيات المزايا.

## 2. قائمة مزايا الذهبي المسجلة

- فتح جميع الأسئلة والاختبارات والتدريبات، وجميع المواد المنشورة وتنزيلها.
- مدرس ذكي لكل مادة، شرح متعدد الأساليب، تبسيط، حل خطوة بخطوة، تحليل الصور، توليد الأسئلة والتدريبات العلاجية، واختبار شفهي تفاعلي.
- خطة يومية متكيفة، جدول حسب المستوى، تحليل القوة والضعف، مؤشر تقديري للاستعداد، مراجعة متباعدة، سجل أسبوعي ومقارنة التقدم.
- محاكاة وزارية بمؤقت وتصحيح وتقرير، اختبارات حسب الوقت والصعوبة، عشوائية، وإعادة الأسئلة الخاطئة.
- واجهة ذهبية، شارة VIP، تخصيص الألوان، دفتر قوانين وملاحظات، مفضلة، مجلدات، بحث متقدم، إشعارات ومزامنة سحابية.
- أوسمة وإنجازات وتحديات أسبوعية وسلسلة دراسة وشهادات وإحصائيات ساعات وأهداف يومية وشهرية.

## 3. ما هو منفّذ فعليًا وما هو مجرد تسجيل للخطة؟

**منفّذ في هذه الدفعة:**
- مدة كل خطة في كتالوج التطبيق.
- عرض مزايا الباقتين في شاشة الخطط.
- مفاتيح مركزية لصلاحيات الميزات مع قاعدة منع افتراضية للمفاتيح غير المعروفة.
- اختبارات منطق المدد وفصل الصلاحيات.
- ترحيل SQL لتوحيد مدد أكواد التفعيل غير المستخدمة.

**موجود مسبقًا في V23 ويحتاج تحققًا حيًا قبل اعتباره جاهزًا للإنتاج:**
- المساعد الذكي: يوجد عميل وخادم، ويتحقق الخادم من اشتراك Gold الفعّال قبل الخدمة؛ يحتاج نشر Edge Function وإعداد الأسرار واختبار اتصال حقيقي.
- التقدم والإنجازات والمفضلة والمجلدات والبحث وبعض أدوات المراجعة لها ملفات/واجهات موجودة، لكن لا يعني ذلك أن جميع عناصر قائمة VIP أصبحت مكتملة أو متزامنة سحابيًا.

**لم تُنفّذ كوظائف مكتملة في هذه الدفعة، رغم تسجيلها ضمن صلاحيات/وصف الخطة:**
- فحص الصور وحل المسائل بالصور، المدرس الصوتي/الشفهي التفاعلي، التوليد المتقدم للاختبارات، محاكاة وزارية مكتملة، الجدول المتكيف والتنبؤ بالاستعداد، الإشعارات الذكية، المزامنة السحابية، شهادات الإنجاز، وتخصيص الثيم الذهبي.
- التنزيل الكامل لكل المواد لا يمكن تأكيده قبل توفير ملفات المواد وروابط التخزين واختبارها.
- «جميع الأسئلة» لا يمكن أن تظهر حتى يُستكمل بنك الأسئلة ويُراجع ويُنشر؛ تقرير V23 السابق يسجل صفر أسئلة معتمدة.

**تنبيه تقني مهم:** مفاتيح `PremiumFeatureAccess` هي طبقة تعريف/عرض في التطبيق وليست بديلًا عن التحقق الخادمي. أي ميزة تحمي بيانات أو تنفذ عملية مدفوعة يجب أن تتحقق من اشتراك الطالب في Supabase/الخادم أيضًا قبل إطلاقها.

## 4. السعر والتفعيل

- السعر بقي فارغًا عمدًا؛ لم يقدّم صاحب المشروع سعرًا معتمدًا.
- لذلك زر طلب الدفع يبقى مغلقًا إلى أن يعتمد السعر وبيانات الاستلام.
- مدد الأكواد غير المستخدمة تُضبط بالترحيل إلى 30/75 يومًا. الأكواد المستخدمة لا تُغيّر حفاظًا على السجل.
- يجب تطبيق ملف SQL على مشروع Supabase الحقيقي قبل اعتبار مدة الأكواد مطبقة على الخادم.

## 5. نتائج التحقق

- اجتاز `scripts/validate_project.py` فحوصه البنيوية.
- فُحصت صياغة JSON والأصول والاستيرادات النسبية وإعدادات Android وفق تقرير أداة التحقق.
- لم تتوفر أوامر Flutter/Dart في بيئة العمل؛ لذلك لم يمكن تشغيل `flutter analyze` أو `flutter test` أو بناء APK.
- لم يُنفّذ ترحيل SQL على قاعدة Supabase الحية ولم تُجرَ اختبارات هاتف فعلية.

## 6. الحكم

تم تحديث **كتالوج الخطط ومفاتيح صلاحيات VIP والمدة المعتمدة** داخل مصدر V23، مع إبقاء السعر غير مخمّن وعدم الادعاء بأن كل خدمة VIP أصبحت تعمل. الحزمة الناتجة مصدر كامل محدث، وليست APK إنتاجيًا مختبرًا. يجب تطبيق ترحيل Supabase ثم تشغيل اختبارات Flutter والبناء على بيئة Android قبل النشر.
